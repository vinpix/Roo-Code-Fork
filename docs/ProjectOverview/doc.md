# Project Overview Summary

This folder contains the general documentation and high-level architecture of the Roo Code project.

## What it is

Roo Code is an AI-powered autonomous agent for VS Code that can write code, run commands, and manage complex development tasks.

## Key Modules

- `src/core`: Core logic and agent behavior.
- `src/services`: External integrations (MCP, Browser, Search, etc.).
- `webview-ui`: The user interface for the VS Code extension.
